# 逐图风格卡系统

## 原子原则

每张摄影参考图是一张独立风格卡。室内／室外描述场景；理光式快拍、富士式胶片色、佳能式肤色、索尼式清晰数码、传统胶片和杂志扫描描述成像倾向。品牌词表达观感，不声明真实器材。

每次生成只选一张主风格卡。主卡定义一个可变化的**风格包络**：成像倾向、光线传播、色彩响应、黑白层次和介质质感构成摄影DNA；原图的具体地点、人物位置、动作、道具排列和画面轮廓只是一次实例。参考图提供风格包络；Good Case校准完成度；模板图约束印花和可转译内容。

`composition_behavior`记录偏心、留白、透视张力、层次组织等抽象规律，不记录可复刻的主体坐标或场景平面图。`human_state`记录松弛、运动、内收、偶然回头等状态，不绑定原图姿势。七项综合色与人物状态组成可审核的 `styleFingerprint`，定义见 [photographic-truth-and-color.md](photographic-truth-and-color.md)。

## 接收新参考图

1. 保存原图到Skill资产库或用户指定的独立参考库。
2. 逐张分析，不先寻找共同点。
3. 记录视觉可见事实和成像倾向推断。
4. 给出独立ID并加入目录。
5. 通过用户反馈调整调用权重，不覆盖原始分析。

## 选择风格卡

依据模板情绪、产品使用行为、批次多样性和历史反馈选择。场景大类不限制风格：同一厨房可调用暖色负片、柔暖人像、粉金漏光或低饱和生活胶片。

选卡后先锁定3至5项摄影DNA，再做场景变奏。每张至少从以下维度主动改写三个：

- 地点与空间拓扑：房间、街区、入口、动线和前中后景关系。
- 主体位置与画面轮廓：人物和宠物的相对位置、比例、朝向和负空间分布。
- 人物动作与叙事时刻：行为、视线、重心和快门前后发生的事。
- 机位与镜头几何：高度、方向、距离、焦段感和透视关系。
- 美术与道具系统：家具、植物、食物、生活物件和材质组合。

完成标准是“同一种摄影师眼光下的新场面”。若一眼能把成片与参考图按人物轮廓、道具位置和空间分区重叠，继续改写场景。

批次内连续三张避免重复同一成像倾向、光线结构、景别和人物动作。新的Good Case按 `approved_reference`、`approved_usable` 或 `borderline_positive` 分级；只提高用户明确认可维度的权重，不自动成为全局风格。选卡时结合样本量与 Good Case 率：高表现卡增加调用，持续零 Good Case 且样本充足的卡暂停并重新分析，同时保留少量探索额度，防止批次收敛成单一视觉。

## 参考距离检查

生成提示词先写摄影DNA，再写全新的生活事件。提示词明确列出三项以上场景变奏，并把参考图限定为色彩、光线、质感和镜头行为来源。视觉检查逐项确认：

- 场景拓扑已经变化。
- 人物／宠物的整体轮廓与位置关系已经变化。
- 主要动作和道具关系已经变化。
- 保留下来的相似性可以用摄影语言解释，而非用相同布景或姿势解释。

四项中前三项全部成立，才进入候选审核。

### 主卡显影门禁

主卡选择完成后，从光线几何、色彩曲线、镜头行为、介质质感和人物状态中锁定3至5项可见DNA，并逐项进入计划与提示词。视觉检查需要在成片中找到至少三项对应证据；只有“清新”“日系”“胶片”一类宽泛形容，或成片落入无辨识度的通用商业生活照时，判定风格卡未显影并重做。

参考图中的脸只提供选角气质：自然、清爽、年轻、具有日系写真感。生成使用不同的虚构东亚青年人物，单人图按男性30%、女性70%滚动分配，面部、发型和穿搭保持批次差异。

## Good Case 与 Bad Case

Good Case承担成片完成度和有效策略的证据，不能替代主摄影参考。若能取得当时的生成提示词、单图计划或生成参数，连同图片一起分析并记录：

- 哪一段提示词有效控制了光线、色彩、人物状态、构图或产品融合。
- 哪些效果来自参考图，哪些来自模板内容和导演巧思。
- 哪些描述可以复用，哪些只适用于当前模板。

Bad Case保留原图和用户原话，明确失败属于摄影气质、场景、人物比例、宠物身份、产品物理、印花融合或构图。反馈只调整相关卡片和策略权重，避免把局部失败扩张成全局禁令。

整张通过同样按维度学习：用户认可整体成片时，记录已确认的氛围、产品或摄影优势；没有被单独确认的宠物互动、印花细节或构图策略保持未决。维度化记录从本次任务提供的本地反馈索引读取。批量生产还需读取其中的 `batchReviews`，使用全量已生成数、明确决定数、待定数和正式入库数分别计算口径，避免把“只登记点选通过项”的批次误报为高通过率。


## 本地资源

风格卡目录、参考原图和反馈案例由任务提供，保存在 Git 忽略的本地资源目录或仓库外。每次选卡读取本地目录的当前停用与恢复决定；缺少真实参考图时暂停生成并说明缺失资源。仓库不携带个人素材、逐图目录、历史案例明细或统计排名。

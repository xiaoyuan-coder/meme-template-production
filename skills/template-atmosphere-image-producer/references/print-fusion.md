# 产品与印花融合

## 决策对象

每张模板先判断：背景类型、载体底色、背景处理、印花位置、相对尺寸、边缘处理、材质呈现和表面形变。

```text
source_background_type
carrier_base_color
background_treatment
placement_zone
relative_scale
edge_treatment
material_rendering
fold_or_surface_warp
visibility_guard
```

## 背景处理

| 模板类型 | `background_treatment` | 目标 |
|---|---|---|
| 白底且主体边缘清楚 | `remove_white` | 去除外围白底，保留白毛、眼白和主体内部白色 |
| 单一彩色色块 | `match_carrier_color` | 产品底色匹配背景色，让边界自然消失 |
| 色块与载体难以统一 | `compact_color_patch` | 缩小为主动设计的局部图案、徽章或海报块 |
| 完整边框、卡片或海报 | `preserve_designed_frame` | 保留结构并控制尺寸，形成明确版式 |
| 不规则拼贴、纸洞、贴纸 | `extract_irregular_subject` | 沿视觉轮廓抠图，保留核心边缘机制 |
| 复杂场景型画面 | `preserve_full_scene` | 中小尺寸保留完整关系，避免覆盖全部产品 |

## 服装位置

- 默认视觉中心位于上胸至胸腹交界，避开领口、腋下和腰部强褶皱。
- 紧凑头像使用中小尺寸居中或左胸小图。
- 纵向图案沿身体中轴并保留领口、腰线空间。
- 横向双主体或文字可以加宽，同时控制高度。
- 不规则拼贴按视觉重心微调。
- 外套敞开时保证核心主体完整露出。

印花需要清楚、可识别并属于产品。彩色矩形、过大胸前图和跨越强褶皱的核心文字需要主动重构。

## 色彩融合

- 印花的综合色、黑位和对比度跟随载体材质调整，避免像一张高饱和、高反差的图片浮在表面。
- 当印花显得过深时，优先轻微降低印花自身的密度与对比度，让载体底色进入中间调；同时保留人物、文字和关键轮廓的辨识度。
- 浅化只作用于印花的产品呈现，不改写模板原图资产，也不把白毛、眼白、内部留白或高光误当成可删除的背景。
- 布料载体保留吸墨、纤维、褶皱和光照造成的自然明暗变化。最终以整图观看时“像真实印上去”为准，不追求印花局部的最高反差。

## 产品物理

| 产品 | 物理要求 |
|---|---|
| T恤／长袖／卫衣 | 布料褶皱、印花吸墨感、合理胸前区域和自然遮挡 |
| 帆布包 | 下垂、受力、透视、包带方向和身体遮挡 |
| 水杯 | 圆柱弧面收缩、把手方向、反光与握持关系 |
| 抱枕 | 鼓起、压痕、边缘弯曲和人物／宠物施力 |
| 毛毯 | 图案进入纤维与绒面，在大面积连续起伏中保持连贯；边缘、明暗和清晰度随折叠共同变化 |
| 冰箱贴 | 保持真实小尺度、厚度和投影，同时占据干净对比区，并通过人物贴取、便签关系或视线形成清楚商品识别 |

## 验收

图案需要像经过产品设计后真实印制。检查底色、色彩密度、对比度、尺寸、位置、边缘、材质、变形和光线是否统一；明显呈现矩形图片覆盖产品或印花黑位过重、浮在载体表面的项目进入修改。小型产品同时执行商品识别门禁：保持真实尺度，并在3:4整图预览下看清产品类别和核心图案。
